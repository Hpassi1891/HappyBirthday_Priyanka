# Priyanka's Birthday Room Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan.

**Goal:** Build a pink, cute, interactive multi-scene birthday website for Priyanka (spec: `.decibel/specs/2026-10-06-birthday-room-design.md`).

**Architecture:** Static site. `index.html` hosts a single `#stage`; a tiny scene manager (`js/main.js`) mounts one scene module at a time (`js/scenes/*.js`). Pure logic (door answer check, countdown, blow detection thresholds) lives in `js/lib/*.js` so it can be unit-tested with Node. Copy and image lists live in `content/*.json`.

**Tech Stack:** HTML/CSS/vanilla ES modules, GSAP (vendored in `vendor/`), Canvas, Web Audio API, Node `node:test` for logic tests, Playwright (pre-installed Chromium) for smoke tests. Deploy: Cloudflare Pages / Netlify.

### Task 2: Door logic (TDD)
**Files:** Create `js/lib/door.js`, `tests/door.test.mjs`
- [ ] Step 1: Failing test:
```js

import { checkAnswer } from '../js/lib/door.js';
test('rakshas opens', () => assert.equal(checkAnswer('  Rakshas ').result, 'open'));

test('empty is wrong', () => assert.equal(checkAnswer('').result, 'wrong'));
```
- [ ] Step 2: `node --test tests/` -> FAIL (module missing).
- [ ] Step 3: Implement (answers compared by SHA-256 hex hash precomputed at build time; for sync testability use a small FNV-1a string hash with salt, constants `OPEN_HASH`, `NAME_HASH` generated by `node -e`):
```js
const norm = s => s.trim().toLowerCase();
const h = s => { let x = 2166136261; for (const c of 'pk11:' + s) { x ^= c.charCodeAt(0); x = Math.imul(x, 16777619); } return (x >>> 0).toString(16); };
export const OPEN_HASH = h('rakshas'), NAME_HASH = h('himanshu');
export function checkAnswer(raw) {
  const v = h(norm(raw));
  if (v === OPEN_HASH) return { result: 'open' };
  if (v === NAME_HASH) return { result: 'funny' };
  return { result: 'wrong' };
}
```
- [ ] Step 4: tests PASS. Step 5: commit `feat: door answer logic`.
